# 找一找是哪个

一个为 iPad 和手机触控优化的中文听故事问答小游戏。

## 玩法

1. 点击“开始听故事”，游戏会朗读一个中文小故事。
2. 听完后回答 5–7 道问题，每道题都会自动朗读，并提供 3 个大图选项。
3. 点击黄色“提交答案”按钮后，游戏会显示并朗读本次获得的星星数。
4. 结果页可选择“1 再来一次”或“2 下一关”。重玩会使用同一个故事，答对继续得星，答错不扣星。
5. 右上角的圆形按钮可以随时退出到主页。

## 特点

- 中文语音朗读（使用设备自带的中文语音）
- 问题和三个选项都会朗读，点击图形时会再读出选中的名称
- 提交后会播报本次和累计星星数，并语音询问“再来一次还是下一关”
- 大尺寸图形选项，方便还不识字的小朋友独立游玩
- 轻快背景音乐和庆祝音效
- 随机组合的不重复故事
- 每个故事最多 7 题
- iPad 横屏、竖屏和手机自适应
- 无广告、无外部依赖，进度仅保存在当前设备浏览器中

## 本地运行

直接用浏览器打开 `index.html` 即可。在 iPhone/iPad 上建议通过 GitHub Pages 链接使用 Safari 打开，以确保 JavaScript 和语音功能正常运行。
